Studio storage check & backup

Your Prompt Machine vocab, characters, drafts, ad-lib pads, bars and AUTOMATICS songs are saved only in this browser on this device. A different browser, a private tab, the Google app's built-in browser or a home-screen app each keep separate storage, so your work can look "gone" there when it's actually still in the original one. This page only reads storage. It never deletes anything.

2 · Back up

Downloads a JSON file with every ZigFlames text setting from this browser (vocab, characters, drafts, looks, loop lab, MJ params, bars, ad-lib pad names). Audio samples and AUTOMATICS songs aren't included. Use AUTOMATICS → Songs to export those.

3 · Restore into this browser

Merge only: by default it adds items this browser doesn't have and leaves existing ones alone. If you tick "replace", each current value is copied to pm.importBackup.* before it's replaced. Nothing gets deleted either way.
