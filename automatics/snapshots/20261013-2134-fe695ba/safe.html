Safe Open

If the machine looks old, hard refresh or use Safe Open — old Google results may be stale.

Open AUTOMATICS in a dedicated window so a leftover unlocked tab or Google search history from your main browser profile is less likely to expose the machine.

Recommended setup

  1. Install as app (PWA) — in Chrome/Edge open AUTOMATICS, then Install / “Cast …” / app menu → Install ZigFlames · AUTOMATICS. Launch from that app icon only.
  2. Dedicated profile — create a Chrome/Edge profile used only for Zig Studio (no personal Google search, no random extensions). Sign into that profile only when you work.
  3. Lock when you step away — use LOCK NOW or Session-only unlock so closing the window clears access.
